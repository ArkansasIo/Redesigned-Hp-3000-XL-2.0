# HP 3000 XL Color GUI PNG Assets

This directory contains original redesigned color GUI artwork for the Android 10+ recreation.

## Screens

- boot_screen.png — custom startup/diagnostic screen
- desktop.png — color desktop and taskbar
- start_menu.png — classic Start menu layout
- file_explorer.png — file manager
- word_processor.png — word processor
- spreadsheet.png — spreadsheet
- calendar.png — calendar/PIM
- terminal.png — terminal shell
- code_editor.png — programming workspace
- calculator.png — calculator
- system_settings.png — system settings

The PNG artwork is visual UI material. Runtime controls remain native Jetpack Compose controls so the application is interactive rather than a static screenshot.

## Design boundary

Artwork is newly created for this independent recreation. The project does not redistribute HP proprietary ROMs, Windows CE binaries, extracted firmware, or original copyrighted device assets.
