HP 3000 XL · COLOR MOBILE EDITION
Independent recreation
Handheld desktop project

Classic handheld computing, redesigned for Android.

Redesigned HP 3000 XL 2.0 is an independent, full-color handheld desktop recreation inspired by the HP 300LX and Windows CE era. This project brings a familiar desktop, built-in productivity tools, and a modular application platform to modern Android devices.

Platform highlights

Desktop shell

Color desktop, Start menu, taskbar, shortcuts, window controls, clock, and display themes.

Productivity suite

Document and spreadsheet workspaces, contacts, calendar, inbox, tasks, notes, and calculator.

System tools

Control Panel, task manager, device information, storage and battery status, and settings models.

Application platform

Kotlin, Jetpack Compose, SQLite persistence, app registry, and Android-backed service APIs.

Connectivity foundations

Internet workspace, network settings, and a simulated terminal with an allow-listed command set.

Android support

Designed for Android 10+ with touch-friendly layouts and support for phones, tablets, and handheld PCs.

Project status

The repository contains the Android/Kotlin application and an automated APK build workflow. Refer to the source and workflow pages for the latest implementation and build results.

Android project · GitHub Actions build

This website is a project overview. It does not run or emulate the Android application in the browser. APK availability depends on successful workflow runs and published artifacts.

Build the Android app

Clone the repository and run the Gradle build from its root directory:

./gradlew assembleDebug

Expected debug APK: app/build/outputs/apk/debug/app-debug.apk

Project principles

This is an independent implementation. It does not include Microsoft Windows CE or HP proprietary firmware, ROM images, binaries, source code, or copyrighted system assets.
