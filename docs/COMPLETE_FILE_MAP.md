# Complete File Map

## Runtime
- `core/` — CE runtime coordination and events
- `os/` — hosted operating-environment lifecycle, services, processes and permissions
- `services/` — Android-backed system service interfaces and adapters
- `hardware/` — display, input, audio and storage abstractions
- `platform/` — platform storage, settings and input APIs

## Applications
- `apps/system/` — File Explorer, Control Panel, Task Manager and System Information models
- `apps/office/` — Pocket Word and Pocket Excel engines
- `apps/pim/` — Contacts, Calendar and Inbox models
- `apps/calculator/` — calculator engine
- `apps/development/` — code editor, language catalog and terminal development tools
- `apps/games/` — Solitaire and Minesweeper models

## Packages
- `packages/` — HP application package manifest and validation
- `package/` — package installation/update abstractions

## Development
- `development/` — code workspace and language integration
- `terminal/` — terminal session/profile abstractions
- `languages/` — supported language catalog

## UI
- Compose desktop shell
- Start menu
- Taskbar
- Window chrome
- Built-in application screens
- Color Mobile Edition visual system

## Firmware model
- `firmware/board/`
- `firmware/boot/`
- `firmware/kernel/`
- `firmware/drivers/`
- `firmware/audio/`

Firmware files describe an independent hardware abstraction/model. They are not proprietary HP firmware or Windows CE binaries.
