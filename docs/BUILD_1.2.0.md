## Major additions

- CE-style terminal subsystem
- Safe built-in terminal commands
- Multi-language development catalog
- Kotlin, Java, C, C++, Rust, Python, Lua, JavaScript, TypeScript, Shell, BASIC 2026 and Assembly language definitions
- Code workspace abstraction
- Firmware/boot architecture
- HID keyboard/mouse input architecture
- Touchscreen input architecture
- Linux/Android kernel integration boundary
- Update/package framework

This build is a software recreation. It does not distribute proprietary HP firmware, ROM images, Windows CE binaries, or original copyrighted device audio.
