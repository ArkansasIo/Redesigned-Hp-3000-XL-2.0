# Version / Expansion Matrix

| Version | Channel | Expansion |
|---|---|---|
| 0.1.0-pre-alpha | pre-alpha | Core shell, apps, Android runtime |
| 1.0.0 | stable | Core CE-style OS experience |
| 1.1.0 | expansion | Hardware services, keyboard/mouse, improved PIM |
| 1.2.0 | expansion | Firmware model, boot diagnostics, update manager |
| 1.3.0 | expansion | Linux/Android kernel integration boundary |
| 2.0.0 | major | Hardware/emulator platform and extended package SDK |

Each expansion must preserve the existing application/package APIs where possible and provide migration notes for breaking changes.
