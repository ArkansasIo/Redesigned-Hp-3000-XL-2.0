# SIMH media import

The Android media importer copies a file selected by the user through Android's Storage Access Framework into the app-private machine workspace.

## Contract
- The caller must obtain the URI through an explicit user selection flow (for example, Android's Open Document picker).
- Imported files are copied, not executed.
- Output names are generated by the app; source filenames cannot traverse the destination path.
- The default size ceiling is 8 GiB and can be reduced by callers.
- Empty files and failed/oversized copies are rejected and partial output is deleted.
- Media is kept under the selected machine's private files/simh/<machine>/ directory.

## Not yet wired into the screen
This helper is source code for the next UI step. The current screen does not yet present a file picker or mount media into SIMH. Importing an image does not mean the simulator can read or boot it.

## Legal and safety
Only import images you are authorized to use. Do not bundle proprietary HP firmware, operating-system media, disk packs, or tapes in the APK. Media parsing and machine boot remain the responsibility of the future tested native SIMH integration.
